# 输入框 + 状态刷屏修复 · 2026-07-18

## 截图所见（桌面左侧 chuang Konsole）
1. 底部「╭─ 输入 │ ╰─」像空壳，光标位置怪  
2. 运行时刷出几十行相同 `⏱ 1m22s · 执行中 …` 状态墙  

## 根因
1. **输入框**用 `╭│╰` + `\x1b[3A\x1b[3C` 回跳光标；HUD/状态行打乱行数后框子碎掉  
2. **HUD** 用 `writeln` + 偶发 `\x1b[1A`；状态行超长**自动折行**后「上移一行」删不干净 → 每 200ms 堆一行  

## 修复
- 输入：改成状态条 + **`❯ `** 提示符，禁止 cursor-up 画框  
- HUD：单行 ≤78 列，用 `\r\x1b[2K` **原地刷新**，禁止 writeln 刷墙  
- 真过程行：先清 HUD 行再 `writeln` 步骤  

## 验收
重启 chuang（须用新编译二进制）。应看到：
- 底部 `就绪 · model · context…` + `❯ ` 可输入  
- 运行中状态在同一行变数字，不刷满屏
