- command runner report 仍只暴露 1200 字符 preview，并在输出超过 preview 或捕获上限时设置 `truncated=true`。

- `native` transport 的 request 和 response body collect 已加 `tokio::time::timeout`，卡住时返回 `native_http_timeout`。
