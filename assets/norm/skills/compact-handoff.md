【skill: compact-handoff · 上下文腾挪】
长会话将超预算或换工人续作时，写一份交接（可落盘，勿整段塞 system）：
1. Primary request（用户原意）
2. Key decisions / constraints（含安全红线原话）
3. Files touched（路径 + 为何重要）
4. Errors & fixes
5. Pending tasks
6. Current work（刚做到哪）
7. Next step（须紧贴用户最近明确要求）
安全相关约束必须原样保留。不要发明用户没说过的批准。
always-on 规矩由 runtime 在 pack 后 repin，交接只补工作态，不重抄 doctrine 全文。
